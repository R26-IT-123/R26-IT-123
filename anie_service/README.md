# ANIE - Academic Note Intelligence Engine

## Overview
ANIE is the academic note evaluation component of the ShareMate application.

## Main Features
- Academic note validation
- PDF text extraction
- Semantic similarity using FAISS
- TF-IDF keyword analysis
- Note quality scoring
- Difficulty level classification

## Technologies
- Python
- FastAPI
- Sentence Transformers
- FAISS
- Scikit-learn

## Workflow
1. Student uploads an academic note.
2. The system extracts text from the document.
3. The note is compared with academic reference materials.
4. Semantic similarity and keyword relevance are analyzed.
5. A quality score and difficulty level are generated.
