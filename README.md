# ShareMate Mobile App

## Project Overview
ShareMate is a smart student-focused mobile app with four core modules:
1. Community-powered Public Transport Live Sharing
2. Private Vehicle RouteSharing & FriendZoneRide
3. Smart Academic Note Sharing System
4. Shared Grocery Shopping & Delivery Module

## Team Members and Responsibilities

### Member 1
Community-powered Public Transport Live Sharing for University Students
FLTS Engine
- Passenger bus tracking
- Route zones
- ETA prediction
- Traffic detection
- Incident reporting
- Bus ID and feedback

### Member 2
Private Vehicle RouteSharing & FriendZoneRide Engine
- Ride cost calculation
- Priority seat allocation
- Friend-seat booking
- Distance-based pricing
- Feedback summarisation

### Member 3
Academic Note Intelligence Engine, ANIE Engine
- Content reliability
- High-quality contributions
- Structured learning support

### Member 4
Shared Grocery Shopping & Delivery Module
- Shopper discovery
- Request handling
- Trust evaluation
- Delivery coordination
